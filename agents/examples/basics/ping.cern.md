# Ping

Each call is one live run of the system's ping command, started over
if it fails part way. It runs on macOS, Linux and Windows, each with
its own form of the command and of what it prints, and Windows prints
in the language of the system, so its answer is read by its numbers
alone.
Given a host name, ping it five times. Answer the average round trip
time in milliseconds and how many of the five replies were lost. When
every reply is lost, answer five lost and no average; a host name that
cannot be resolved is an error.

Type: job
