# Fact Check

Uses:

- cernanto/search
- cernanto/decision
- cernanto/llm

Given a claim about the world, check it against published sources.
Answer whether it is true, false or uncertain, and the sources you
used; a claim the search finds no evidence for, or the sources do not
settle, is uncertain, with the sources read.

Decisions are made with cernanto/decision.
