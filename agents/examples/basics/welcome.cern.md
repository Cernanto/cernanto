# Welcome

Given a name and the id of a greeter, greet that person through that
examples/basics/greeting greeter and answer its greeting.

Uses:

- examples/basics/greeting

## Tests

Uses:

- examples/basics/usher

To test it, greet a person through examples/basics/usher, a greeter that runs as an agent of its own, and through the formal greeter, one linked into this agent, and check that each answer is that greeter's greeting.
