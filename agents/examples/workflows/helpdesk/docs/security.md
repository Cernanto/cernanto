# Security

Every account uses the company password manager and two-factor
authentication; a password is never shared in chat or mail. Production
access is granted by Tom Okafor for the ledger and Priya Nair for the
storefront, reviewed every quarter, and revoked on a person's last day
by Lior Katz.

A lost or stolen laptop is reported to Lior Katz the same day; the
device is wiped remotely. Customer data leaves the production systems
only through the export tool, never by copy, and is deleted from
laptops within a week.

Suspected phishing is forwarded to security@acmeledgers.example and
never answered. A security incident is reported to Tom Okafor at once,
day or night.
