# The loop

The refund policy as a prompt-driven agent on the vendor SDK: the
policy is the system prompt, the shop and the chat are tools whose
schemas are written by hand, the model decides which to call, and the
program supplies what the language gives the compiled desk for
nothing: the state on disk so a rerun after a crash resumes, the
idempotency key on the refund, the retries on the API. It reaches the
same sandbox the desk runs on, through the cli.

```
$ npm install
$ export ANTHROPIC_API_KEY=...
$ node --experimental-strip-types refund-loop.ts A-1012 "The notebooks are unused, still in the box. Could I get a refund?"
```

Read it beside `../../workflows/refund-desk.cern.md`.
