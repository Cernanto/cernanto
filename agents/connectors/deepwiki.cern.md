# DeepWiki

Uses: mcp:https://mcp.deepwiki.com/mcp

Given a public repository, as owner and name, and a question about it,
answer the question from the repository's documentation as DeepWiki
reads it, which needs no account, and name the pages the answer rests
on: the pages DeepWiki cites for it, or whose titles its answer
names. When the documentation does not answer it, say so: when DeepWiki
has no wiki for the repository, or its answer says the question is not
covered.
