# LLM Prompt Harness

Type: module

Implements: cernanto/llm-prompt
Uses: cernanto/harness

The prompt sent through the coding vendor the plane binds: bind
cernanto/harness with no name, so the vendor `cernanto/harness/default`
names answers, and delegate the one-shot whole, the prompt, every
setting and the attachments handed through as given, the answer as the
vendor gives it. A one-shot that names no model or effort runs on the
vendor's own one-shot defaults. This agent reads no setting itself, so
one binding, the harness's, moves compiles, values and decisions
together.

## Tests

Uses: npm:jimp

The vendor the plane binds must run. The picture the tests carry is
drawn by the tests themselves: a PNG of a few hundred pixels showing
the digits 42 in a large font on white. Every live one-shot of the
tests names `model` "sonnet" at `effort` "low".
